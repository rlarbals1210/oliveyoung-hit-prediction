# MD 검토 규칙 제안

이 문서는 모델이 상품을 자동으로 채택·탈락시키는 스코어카드가 아니다. 표본 119건에서는 예측력을 확정하기 어렵다는 반복 교차검증 결과를 전제로, 출시 초기 상품을 **사람이 다시 살펴볼 순서와 예외 조건**을 정리한 수동 검토 가이드다.

## 사용 범위

- 출시 후 14일 리뷰가 확보된 스킨케어·색조 상품
- 카테고리 TOP 100 진입 여부를 직접 예측하는 자동 의사결정에는 사용하지 않음
- 판촉·재고 결정 전 MD가 리뷰 패턴을 확인하는 보조 체크리스트로만 사용

## 1차 검토: 데이터가 판단 가능한가

1. 14일 리뷰 수가 지나치게 적으면 점수화하지 않고 `관찰 연장`으로 분류한다.
2. 출시일은 최초 리뷰일로 추정했으므로 프로모션·사전 체험단 등 실제 출시 정보가 있으면 먼저 교정한다.
3. 현재 누적 리뷰 수·평균 평점·도움돼요 수는 미래 정보가 섞일 수 있어 사용하지 않는다.

## 2차 검토: 초기 신호와 예외를 함께 본다

| 검토 항목 | 확인 질문 | 해석 원칙 |
|---|---|---|
| 리뷰 속도 변화 | 14일 안에서 리뷰가 빠르게 쌓이는 구간이 있는가 | 절대 리뷰 수보다 기울기와 burst를 함께 본다 |
| 평점 분산 | 평균 4.8 안에서도 평가가 갈리는가 | 분산 하나만으로 히트·논히트를 판정하지 않는다 |
| 구매 동기 토픽 | 자발적 효능 언급이 초기에 나타나고 이후 대중 리뷰로 확장되는가 | BERTopic 비율은 행동 지표와 교차 확인한다 |
| 약점 그룹 | 조용한 만점형 또는 분산형에 해당하는가 | 14일 결과를 확정하지 않고 21·28일 재평가 대상으로 보낸다 |

## 3차 검토: 2단계 관찰

- **14일:** fast hit 후보를 조기에 선별하되 자동 판정하지 않는다.
- **21·28일:** 조용한 만점형과 분산형 상품을 재평가한다.
- 관찰 윈도우를 늘리면 전체 CV AUC는 낮아졌지만 두 약점 그룹의 OOF 평균 점수는 개선됐다. 따라서 모든 상품을 늦게 판단하기보다 예외 그룹만 재검토하는 2단계 절차가 적절하다.

## 중단 조건

- 오프라인 매출·검색량·광고 노출을 확인할 수 없으면 판촉 효과나 실제 판매 성과로 해석하지 않는다.
- 리뷰 작성자는 전체 구매자를 대표하지 않으므로 고객 전체의 선호로 일반화하지 않는다.
- 표본을 확대해 외부 검증하기 전까지 임계값 기반 자동 점수나 발주량 결정에는 사용하지 않는다.

근거 수치와 검증 과정은 [`validation_results.md`](validation_results.md)를 참고한다.
